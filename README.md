# SauceDemo – Manual Testing Project

## Project Overview
This project focuses on manual testing of the SauceDemo web application to evaluate its main functionalities and identify potential issues.

The project was created as an independent QA practice project to apply manual testing concepts and demonstrate practical testing skills.

## Application Under Test
[ SauceDemo ](https://www.saucedemo.com/)

## Testing Scope
The following modules were covered:

- Login
- Product Listing
- Product Details
- Shopping Cart
- Product Sorting
- Checkout

## Testing Activities
- Application Exploration
- Test Planning
- Test Scenario Design
- Test Case Design
- Test Execution
- Test Results Documentation

## Tools & Technologies
- Manual Testing
- GitHub
- Google Chrome
- Markdown
